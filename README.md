# Mem0 AI Chatbot

An AI-powered memory-enabled chatbot that supports multi-thread conversations and long-term memory retrieval using Mem0 and FastAPI.

## Features

* Multi-thread conversation management
* Long-term memory storage and retrieval
* Context-aware AI responses
* FastAPI backend
* Modern dashboard-style frontend
* GitHub version control

## Tech Stack

* Python
* FastAPI
* Mem0
* HTML
* CSS
* JavaScript
* Git & GitHub

## Project Overview

This project enables users to create multiple conversation threads while maintaining persistent memory across interactions. The chatbot can retrieve relevant past conversations and generate context-aware responses using LLM integration.
